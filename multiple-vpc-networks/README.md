# Working with Multiple VPC Networks

[Go to lab at skills.google](https://skills.google/paths/77/course_templates/35/labs/630503)

## Overview

In this lab, you create several VPC networks and VM instances and test connectivity across networks. Specifically, you create two custom mode networks (managementnet and privatenet) with firewall rules and VM instances, as shown in this network diagram:

![Network Diagram](https://cdn.qwiklabs.com/cczBwABQnb2t4cjbJ2gbDzcwAZ8dLDOZOtux5pz0YM4%3D)
The mynetwork network, its firewall rules, and two VM instances (mynet-notus-vm and mynet-us-vm) have already been created for you in this Google Skills project.

## Objectives

In this lab, you learn how to perform the following tasks:

- Create custom mode VPC networks with firewall rules
- Create VM instances using Compute Engine
- Explore the connectivity for VM instances across VPC networks
- Create a VM instance with multiple network interfaces
